## 3.2 Query benchmark: chunk intervals (warm cache)

Program: src/benchmark.py with queries in src/queries.py.
Client: psycopg2 2.9.13 (Python 3.11.9). Timer: Python time.perf_counter, from statement
submission (execute) until the last result row is received (fetchall).
Machine: DESKTOP-Q9RBV34. One warm-up then five measured runs per query and table, run sequentially.
ANALYZE was run on all three tables after loading. No loaders or assignment background jobs ran
(only TimescaleDB's built-in telemetry and job-log retention jobs were scheduled).
Session: 2026-10-08 18:09:51.509 to 18:10:52.290 CAT = 60.8 s.
All five queries returned matching results on all three tables (tolerance 0.001).
Per-run CAT start/end times and durations: results/bench_chunks_runs.csv.
