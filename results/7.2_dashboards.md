# 7.1 / 7.2 Grafana dashboards

Grafana OSS (Docker container `grafana_smartgrid`, port 3000), provisioned from files:
- Data source `SmartGrid` (uid smartgrid): grafana\provisioning\datasources\energy.yaml
- Dashboards: grafana\provisioning\dashboards\raw.json and aggregate.json, generated by src\dashboards.py

Both dashboards: timezone Africa/Kigali, default range 2026-09-22 00:00 to 2026-09-29 00:00 CAT,
template variable $meter (default 1000000000), the same five panels:

| Panel | Raw source | Aggregate source |
|---|---|---|
| Hourly regional energy (kWh) | energy_readings JOIN meters, time_bucket 1 hour | energy_hourly_region |
| Daily network energy (kWh) | energy_readings, time_bucket 1 day | energy_daily_meter |
| Network energy per seven-day period from 1 Sep (kWh) | energy_readings | energy_daily_meter |
| Daily energy for meter $meter (kWh) | energy_readings WHERE meter_id = $meter | energy_daily_meter WHERE meter_id = $meter |
| Completeness by region (%) | energy_readings JOIN meters | energy_15min_region / reading_count |

The time filter in every query snaps $__timeFrom()/$__timeTo() to whole CAT days
(time_bucket('1 day', ..., 'Africa/Kigali')), so both dashboards cover exactly the same rows.

Visual check (22-29 Sep, meter 1000000000): both dashboards show 992.6 MWh for the
22-28 Sep period (matches 992,560.3 kWh in 5.1), the same weekday/weekend daily pattern and
identical regional completeness (98.96-99.03 %).
