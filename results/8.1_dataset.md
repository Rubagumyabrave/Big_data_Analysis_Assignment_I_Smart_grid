# 8.1 Chronological dataset and features

Script: src\forecast_8_1_dataset.py (run 2026-10-09 09:27:22-09:27:44 CAT)
Outputs: data\forecast_dataset.pkl, results\8_1_forecast_dataset.csv, 8_1_features.csv, 8_1_dataset_preparation.txt

Dataset: one row per region and CAT hour, sum(energy_kwh) from cleaned energy_readings JOIN meters,
1 Sep 00:00 to 29 Sep 00:00 (exclusive).
- 6,720 rows = 10 regions x 672 hours; absent region-hours: 0
- Readings per region-hour: min 1,562, median 1,584, max 1,597 (planned 1,600); the shortfall is
  the ~1 % missing readings. Targets keep observed totals (not scaled up).
- Total 3,853,704.346816 kWh = cleaned table total.
- Handling: an absent hour would stay NaN (never filled with 0); rows with any missing predictor are
  excluded; no imputation.

Forecast origin: 00:00 CAT of the target day. Every feature uses only hours ending at or before it.

| Feature | Lag / window | Earliest usable target |
|---|---|---|
| lag_24h | lag 24 h | 2026-09-02 00:00 |
| lag_48h | lag 48 h | 2026-09-03 00:00 |
| lag_168h | lag 168 h | 2026-09-08 00:00 |
| prev_day_mean | 24 h window ending at origin | 2026-09-02 00:00 |
| prev_week_same_hour_mean | 168 h window (7 same-hour values, lags 24..168 h) | 2026-09-08 00:00 |
| hour | calendar, no lag | 2026-09-01 00:00 |
| dow | calendar, no lag | 2026-09-01 00:00 |
| region | categorical, no lag | 2026-09-01 00:00 |

Leakage checks (latest source hour end <= origin, all 6,720 rows): all five lag/window features True.
Example: target 22 Sep 18:00 (origin 22 Sep 00:00) uses lag_24h from 21 Sep 18:00.
