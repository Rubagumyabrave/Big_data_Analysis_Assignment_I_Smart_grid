# 7.3 Raw vs Aggregate dashboard verification

Script: src\verify_dashboards.py
Method: every panel query from raw.json and aggregate.json was sent through Grafana's
/api/ds/query endpoint (the same path the browser uses) for
2026-09-22 00:00 to 2026-09-29 00:00 CAT, $meter = 1000000000.
Results were compared cell by cell, keyed on time / region / series name.
Tolerance: 0.001 kWh for energy, 0.000001 percentage points for completeness.

| Panel | Raw rows | Agg rows | Values compared | Unmatched keys | Max abs diff | Result |
|---|---|---|---|---|---|---|
| Hourly regional energy (kWh) | 168 | 168 | 3,360 | 0 | 0.000000000 | PASS |
| Daily network energy (kWh) | 7 | 7 | 14 | 0 | 0.000000005 | PASS |
| Network energy per seven-day period from 1 Sep (kWh) | 1 | 1 | 2 | 0 | 0.000000012 | PASS |
| Daily energy for meter 1000000000 (kWh) | 7 | 7 | 14 | 0 | 0.000000000 | PASS |
| Completeness by region (%) | 10 | 10 | 30 | 0 | 0.000000000 | PASS |

OVERALL: PASS

Notes
- The hourly panel is returned as a wide time-series frame: 168 hourly rows x 10 regions
  x 2 measures = 3,360 values.
- reading_count is hidden in the panels but included in the comparison, which shows both
  dashboards used the same number of readings, not only the same totals.
- The largest difference (1.2e-8 kWh) is floating-point rounding from summing in a different
  order (15-minute rows vs pre-aggregated hourly/daily rows); it is ~80,000x below tolerance.
